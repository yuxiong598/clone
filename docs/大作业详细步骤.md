## 3. 三人完整验收流程（对应作业第 5.3 节）

建议 A、B、C 分别使用三个浏览器配置文件，或三台电脑；也可在一个 MetaMask 中切账户并刷新页面确认角色。三台设备共同演示时应访问同一个前端服务或各自运行同份源码，合约地址必须一致。

现有合约可能已经有订单。下面称第一笔“订单 N”，第二笔“订单 N+1”，以网页真实 id 为准，不要假定一定是 0 和 1。

| 步骤 | 账户 | 页面操作 | 预期及证据 |
| --- | --- | --- | --- |
| 1 | A 买家 | 卖家填 B，金额 30，期限 30 分钟，描述“课程教材订单一”，创建 | 订单 N 为 Created；A 看到付款按钮；记录 createOrder 哈希 |
| 2 | A | 点击付款，在 MetaMask 先确认 approve，等待确认，再确认 deposit | 两笔不同交易；状态 Paid；A 看到确认收货和争议；记录两笔哈希 |
| 3 | B 卖家 | 打开同一个订单 | 有争议按钮，没有确认收货和付款按钮；截图 |
| 4 | A | 再创建一笔 30 个代币的订单并付款 | 订单 N+1 为 Paid；记录真实 id |
| 5 | B | 对 N+1 点击发起争议 | 状态 Disputed；A/B 不显示仲裁按钮；记录 dispute 哈希 |
| 6 | C 仲裁人 | 打开页面与 N+1 | C 看见“判给卖家”和“退给买家”两个按钮 |
| 7 | C | 对 N+1 点击退给买家 | 状态 Refunded；A 余额增加 30；记录 resolve 哈希 |
| 8 | A | 对 N 点击确认收货 | 状态 Completed；B 余额增加 30；记录 confirm 哈希 |

最终两笔订单分别是 Completed、Refunded。每笔都展开“订单时间线”，应按区块号与日志序号排序：

- 订单 N：创建 → 付款 → 确认收货。
- 订单 N+1：创建 → 付款 → 争议 → 仲裁退给买家。

`approve` 是 Token 合约事件，不属于 Escrow 订单事件；其哈希在本次会话记录里单独保留，这是正常的。

**交易记录及时保存：** 每个浏览器/账户导出自己的“本次会话交易记录”CSV，再合并到 `docs/交易记录模板.csv`。刷新会清空会话记录，但已确认的订单事件可以再次从链上恢复。合约页时间线可补找 create/deposit/dispute/resolve/confirm 的哈希；approve 需从钱包或浏览器 Token 交易记录补找。

## 6. 常见问题

### 页面没有订单，或一直同步

先看“事件索引 X / 链上 Y”。如果 Y 大于 X，说明事件仍在扫描或部署区块配置不对。POTOS 每次最多十个区块，旧合约第一次打开可能需要很多请求。代码从部署区块开始扫描，显示进度，失败后在当前会话继续，刷新页面会重新扫描。不要为求快随意把起点改为最新区块，否则会漏旧订单。大规模生产系统应使用持久化索引服务。

### 付款只有一次弹窗，或者第二次拒绝了

第一笔是 Token 的 approve，第二笔是 Escrow 的 deposit。授权成功但拒绝付款时，订单仍是 Created，代币还在买家，allowance 留在链上。可重新点击付款；当前实现会重新授权精确订单金额，再付款。也可在 Token 中 revoke/approve 为 0 撤销授权。

### 第二笔交易报 allowance 不足

确认 approve 的 spender 是当前 Escrow 地址，token 是该订单使用的地址；确认第一笔回执是成功；不要在两笔之间切换账户或网络。代码显式等待授权回执，并在发起第二笔前检查钱包。

### 看不到仲裁按钮

检查顶部地址是否等于链上 arbiter，并确认订单状态为 Disputed。合约部署者、代币 owner 与仲裁人可以是不同地址。前端隐藏按钮是操作引导，最终权限由合约 enforce。

### 退款提示 deadline not reached

退款只能在链上区块时间严格大于 deadline 后执行。前端日期显示使用本地时区；最终判断是合约中的 `block.timestamp > deadline`。争议中的订单需要仲裁，不能直接超时退款。

### Cannot find module / 执行慢

确认在副本目录，运行 `yarn install --immutable`。不要把 Linux node_modules 用 Windows Node 直接运行。`/mnt/c` 安装通常较慢；若需更快，可在 WSL 创建独立的新作业副本使用，绝不能覆盖原 `my-first-dapp`，提交时同步回桌面作业目录。
